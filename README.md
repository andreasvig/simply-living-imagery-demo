# Simply · Living imagery

Static demo of animated covers and interactive parallax.

- Desktop: animation carousel and parallax grid with hover interaction.
- Mobile: vertical feed, centred autoplay, scroll/swipe/phone-tilt parallax.
- Switch between Animation / Parallax and Covers / Showcards.

This repository contains the presentation and selected compressed media only.
